1. 👨‍💻 Developer Dashboard (/dashboard/developer)
Overview (/dashboard/developer): Role readiness score (e.g., 74% ready for Full Stack Engineer), current milestone in progress, and quick stats.
Skill Graph & Gap Analysis (/dashboard/developer/skills): Visual skill tree showing what the target role demands vs. your verified proficiency.
Personalized Roadmap (/dashboard/developer/roadmap): Prerequisite-ordered learning path with resources, project checkpoints, and milestone unlocks.
Skill Assessments (/dashboard/developer/assessments): Quiz & challenge runner to test competencies and earn verified skill badges.
Mentorship & Reviews (/dashboard/developer/mentorship): Request code reviews on milestones, chat with assigned mentors, and schedule advisory calls.
Settings (/dashboard/developer/settings): Switch target career, update profile/portfolio, and manage notifications.
2. 🧑‍🏫 Mentor Dashboard (/dashboard/mentor)
Overview (/dashboard/mentor): Active mentees count, pending review queue, and upcoming calls.
Mentees Directory (/dashboard/mentor/mentees): Mentee progress tracker, individual skill graph drill-downs, and blocker alerts.
Code & Milestone Reviews (/dashboard/mentor/reviews): Inbox for submitted projects/code with markdown feedback editor and rubric grading.
1-on-1 Sessions (/dashboard/mentor/sessions): Availability configuration, call calendar, and post-session action items.
Settings (/dashboard/mentor/settings): Expertise areas, mentee capacity limits, and calendar links.
3. 🛡️ Admin Dashboard (/dashboard/admin)
Platform Analytics (/dashboard/admin): High-level platform health, user distribution, and roadmap completion rates.
Career Pathways (/dashboard/admin/careers): Manage target roles (Frontend, Backend, etc.), skill prerequisites, and readiness formulas.
Skill & Question Bank (/dashboard/admin/skills): Master skill taxonomy and assessment question bank (MCQs, coding challenges).
User Management (/dashboard/admin/users): Search users, approve mentor applications, and manage role permissions.
Settings (/dashboard/admin/settings): Global system configs, auth policies, and audit logs.
